# Pigeon Run

A first playable 3D endless-runner prototype built with **Godot 4**.

## Current prototype
- Three lanes with swipe-to-change-lane controls.
- Swipe upward to jump.
- Keyboard controls for desktop testing (A/D or arrows, Space/Up to jump).
- Forest-like procedural environment.
- Collectible millet and simple block obstacles.
- Score and millet counter.

## Open the project
1. Install Godot 4.x.
2. Download or clone this repository.
3. In Godot, choose **Import** and select this folder's `project.godot`.
4. Open `main.tscn` and press Play.

## Important: placeholder art
The pigeon is currently assembled from simple 3D shapes. The original pigeon photo/model has not yet been added, so its exact appearance, blue leg ring, and wing/leg animations are not implemented yet. The cat chaser, banana-box obstacle, cage, sliding move, camera options, sound, and restart flow are also planned for later versions.

Please add only images/models you have permission to use. Avoid putting personal photos or identifying details in this public repository.

## Android
This is a Godot project, not an APK. Exporting an Android APK requires Godot's Android export setup (Android SDK/JDK and export templates). The project can be developed further before export.
